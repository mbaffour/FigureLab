What it does

Everything the standard workflow gets wrong — fixed

FigureLab is built around the specific tasks that break down when you chain Fiji, Inkscape, and PowerPoint together.

✦

Freeform canvas — like PowerPoint, built for science

Switch from grid to freeform mode and place anything anywhere: images, shapes, text, AI-generated diagrams. Snap to grid, align edges, distribute evenly — then export the whole canvas at publication DPI.

✂️

Pre-use crop editor

Every image passes through a visual crop editor before it touches your figure. Drag to select the region you want to keep, confirm, and only the cropped version enters the canvas. Queue multiple files — each gets its own crop step.

🤖

AI diagram & icon generation

Type a prompt — "phage injecting DNA into bacteria" — and generate a BioRender-style scientific cartoon via Gemini or a local Stable Diffusion instance. Remove the white background automatically and place it directly into your figure.

📐

Scale bars that stay correct after cropping

Pixel math is recalculated from the cropped region, not the original image. Auto-detect embedded scale bars in microscope images. Zeiss LSM calibration populates automatically from the VoxelSizeX tag.

🔍

Deep figure audit

Runs 6+ consistency checks: LUT mismatches across panels, inconsistent brightness scaling, missing calibrated scale bars, font size too small for print, and unequal panel sizes in freeform mode.

⚡

Exposure analysis per panel

Detects overexposed panels (mean >210/255), saturated pixels (>5% clipped to white), underexposure, and low contrast — before you export and before a reviewer notices.

📊

Real ROI quantification

Draw a region of interest and get mean intensity, integrated density, min/max, area in px² and µm² (if calibrated), and a line-profile fluorescence plot. Export all measurements as CSV.

🔢

Threshold-based cell counting

Draw an ROI, set a threshold, and count connected objects using flood-fill. Reports object count, foreground area, and µm² when calibrated. No ImageJ required.

🎨

Per-panel adjustments & one-click standardize

Brightness, contrast, gamma, LUTs, black/white point — all per panel. "Match all to this panel" copies every setting to the rest in one click. Histogram normalization auto-stretches or matches to a reference panel.

🗂️

Layout templates

Eight built-in presets for Nature 2×2, Science single-column, Cell 2×3, poster, supplementary 3×3, and more. Save your own templates and share them as JSON files.

📋

Reproducibility log embedded in every PNG

Every PNG export carries tEXt metadata chunks listing every adjustment made — brightness, LUT, crop, normalization, measurements — readable in FIJI, ImageJ, or any EXIF viewer.

✏️

Annotations as a real vector layer

Arrows, rulers, insets, text boxes, ellipses, counters — export as native SVG elements. Edit in Illustrator or Inkscape after export. Crop-to-shape masking with rectangle, ellipse, or circle clip paths.

📄

Multi-page PDF export

Split any grid figure into a multi-page PDF — choose how many rows per page and FigureLab renders each page independently, then assembles a single PDF. Perfect for supplementary figure sets.

📎

TIFF & LSM metadata reader

Reads µm/px calibration directly from TIFF XResolution tags and Zeiss LSM VoxelSizeX blocks. Drop an LSM and your scale bars are calibrated automatically — no manual entry.

🔗

Share settings via link

Encode your entire layout, style, labels, and annotations into a shareable URL. The recipient opens it, drops their own images, and everything is pre-configured. No server. No account. No image data leaves your machine.

⧉

Panel comparison view

Side-by-side comparison of any two panels with synchronized zoom, a live pixel inspector (R/G/B values on hover), per-panel intensity stats, and a difference overlay that quantifies pixel-level variation between channels or conditions.

Why this exists

The story behind FigureLab

In this post

There is a Ghanaian adage about a piglet quizzing their mother about why she has such a big snout, only for the mother to respond that it was a matter of time before the piglet would grow to experience such a predicament.

I first encountered this particular predicament at a Texas ASM Branch meeting. I was sitting behind someone working on their laptop, wrestling with ImageJ, Inkscape, and PowerPoint. Cropping a microscopy panel. Dragging it into Inkscape. Trying to align a set of figures. I watched for a few minutes before quietly looking away — privately glad it wasn't me, and privately filing it away as something deeply familiar.

Then it was me.

I had a set of N4 phage infection time-course images that needed to become an eight-panel figure for a manuscript. Calibrated scale bars, annotations to add, brightness adjustments to make. I know Fiji well. I know Inkscape well. I have done this before. And yet two hours in, I was exporting the same TIFF for the fifth time because the panel labels kept rendering at the wrong size, the scale bar math was off when I cropped the image, and the SVG I had painstakingly annotated had lost half its arrows when I reopened it. To add salt to injury, I could not seem to align everything perfectly.

I ended up with a figure I did not like, assembled through a process I hated, using tools I respect but that were simply not designed for this job.

So I did what I sometimes do when I hit a wall in this age of AI: I remembered that you can just build things.

The actual problem with figure assembly

To be clear, Fiji is excellent software. ImageJ has been the backbone of biological image analysis for decades, and the community that built and maintains it deserves enormous credit. Inkscape is a genuinely powerful vector editor. The problem is not that these tools are bad. The problem is that making a publication figure involves a very specific workflow — arrange panels in a grid, apply uniform brightness adjustments, add calibrated scale bars, annotate with arrows and labels, export at 300 or 600 DPI — and none of the tools in the standard academic stack were designed specifically for that workflow. You are constantly leaving one application and entering another, re-importing files, re-doing work.

The hidden cost is not the time per se. It is the fragmentation. Your figure exists simultaneously as a Fiji macro, a set of exported TIFFs, an Inkscape SVG, and a mental model of how they all relate. When something changes — a reviewer wants panel C cropped differently or the scale bar moved — you go back to the beginning of the chain.

The specific failures I kept hitting

Scale bar pixel math that ignored my crop region, giving me a bar that was visually correct but numerically wrong. SVG exports from Fiji that silently dropped my annotations when reopened. PNG files that looked fine on screen but were flagged as 72 DPI by the journal submission portal. A session file that crashed when I had more than four large TIFF files loaded.

These are not exotic edge cases. These are the normal workflow for any microscopy-heavy biology paper.

What I built — and what it became

FigureLab started as a single HTML file with a grid, a crop editor, and a scale bar. You open it in your browser. You drag in your images. You build your figure. You export it. No installation, no account, no server, no data leaving your machine. I deliberately kept it as a single file because the last thing a stressed PhD student needs is a dependency to manage.

The core loop was simple: drop images into a panel grid, adjust each one independently, annotate directly on the canvas, apply a journal preset, and export. But the tool kept growing — not because I set out to build something big, but because every workflow it touched surfaced another problem worth solving.

Version 3.1 adds things I did not plan but probably should have from the start. A freeform canvas mode — so figures that do not fit a grid (posters, graphical abstracts, multi-part schematics) have a home. A pre-use crop editor that intercepts every image before it enters the canvas, so you are never cropping the same thing twice in two different tools. A real quantification engine: ROI intensity, integrated density, line profiles, cell counting by threshold. A reproducibility log baked into every PNG export as metadata. And AI-generated scientific diagrams — type a prompt, get a BioRender-style cartoon, place it directly into your figure, background removed.

The ambition changed a little. It is not just a microscopy figure tool anymore. It is closer to what you would get if PowerPoint, ImageJ, and BioRender had a single-file offspring that cared about publication correctness.

On building tools as a scientist

There is a version of scientific training that treats tool-building as a distraction from real science. Get the data, analyze it, write it up, move on. And there is real wisdom in that: time spent building infrastructure is time not spent at the bench.

But there is another version — one I have come to believe more fully as my PhD has progressed — the act of building a tool forces you to understand a problem at a depth that using tools never does. When I wrote the scale bar rendering code, I had to think carefully about what "calibrated" actually means when you have cropped an image. The source pixel width after cropping is not the same as the original image width, and getting that wrong produces a scale bar that looks right but lies.

The act of building a tool forces you to understand a problem at a depth that using tools never does.

I am not claiming FigureLab is finished. It has gaps I know about and probably gaps I do not. But it is real, it runs, and it has already saved me more time than it took to build. That seems like the right bar for whether something was worth doing.

A note on how it was built

FigureLab was built collaboratively with Claude (Anthropic's AI). The ideas, the workflow design, the frustration that motivated it, the decisions about what to build — those are mine. Claude was the implementation partner: writing and debugging the canvas rendering code, the TIFF export logic, the annotation system, the scale bar math. Working this way let me turn a specific scientific frustration into a working tool faster than I could have alone, and I think it is worth being transparent about that.

Getting started

Open it and start building

The interface should be self-explanatory. If it is not, that is a bug. Press ? for the full keyboard shortcut reference.

01

Open in your browser

Click the link above. No download, no account, no sign-up. Chrome recommended. Works entirely offline once loaded.

02

Crop before you start

Drop images and a crop editor opens for each one — drag to keep the region you want, then confirm. The cropped version is what enters your figure. Skip to add as-is.

03

Choose grid or freeform

Grid mode for standard panel figures. Freeform mode for posters, graphical abstracts, or anything that needs custom placement. Switch any time.

04

Adjust, annotate, generate

Per-panel brightness, contrast, gamma, LUTs. Draw arrows, rulers, insets, text boxes. Or generate a scientific diagram with AI and place it alongside your data.

05

Run the audit

Deep Figure Audit checks LUT consistency, exposure, missing scale bars, and font size. Exposure Analysis flags overexposed or clipped panels before a reviewer does.

06

Export with everything embedded

PNG, TIFF, SVG, PDF, JPEG, or WebP at your target DPI. Every PNG carries a full reproducibility log as tEXt metadata — readable in FIJI and ImageJ.

Changelog

What's new in v3.5

Updated 8 July 2026. This release is all about making FigureLab easier to pick up without losing any power — plus a first taste of on-device AI. Same single file, still 100% offline and private.

📦

Submission package (ZIP)

One click bundles everything a journal or lab needs into a single archive — PNG, TIFF, lossless PDF, SVG, session file, metadata CSV, caption, notes, R + Python scripts, reproducibility log, each panel as a separate image, and a provenance manifest. Built on a dependency-free, offline ZIP writer.

📊

Editable PowerPoint (.pptx)

Export each panel as a separate, movable picture at its real position, with the title as an editable text box — then finish the figure in PowerPoint, where most labs finalize. Generated as an OOXML deck entirely in your browser.

🎨

Smart image import

Image cards show dimensions, aspect ratio, and a channel chip detected from the filename (DAPI, GFP, mCherry, Cy5, phase, merge), plus a duplicate-name warning. One click natural-sorts panels by name or assigns colourblind-safe LUTs from the detected channels.

⑃

Split channels & matched panels

Explode a multi-channel composite into separate single-channel panels plus a merge in one click. Assign panels a match group and sync brightness, contrast, gamma, LUT, levels, and scale-bar length across the whole comparison row — so it's processed identically, fair and integrity-safe. Plus a gel/blot splice marker for spliced lanes.

🪄

Simple / Advanced mode

A one-click header toggle hides advanced tools — AI, freeform, measurement, deep audit, normalization — so newcomers see just the core workflow. Nothing is removed; flip to Advanced anytime, and your choice is remembered.

🚀

Start screen & example figure

A blank canvas now guides you: drop images, start from a template, load a session, or click Load example figure to drop in a labelled, scale-barred demo and explore instantly — no files needed.

⌘

Command palette

Press Ctrl/⌘ + K to fuzzy-search and run any action — render, every export format, run the audit, save, presets, match scale, toggle mode. The whole dense feature set, one keystroke away.

🧾

Export preflight

Before you export, see exactly what you'll get: format, final pixel dimensions, physical size in mm & inches, estimated file size, vector-vs-raster status, and integrity warnings (sub-300 DPI, uncalibrated bars, non-white background).

👁️

Colourblind-vision preview

Preview your figure the way deuteranope, protanope, or tritanope readers see it, to check that fluorescence merges stay distinguishable. Display-only — it never changes your exported pixels. New merges also default to colourblind-safe magenta/green.

🤖

On-device AI caption polish

Optional: refine your figure legend with Chrome's built-in Gemini Nano — running entirely on your machine, so nothing is uploaded. It falls back to the built-in rule-based caption if your browser doesn't support it. Privacy-preserving AI, on brand.

❔

In-app Help, FAQ & info chips

A tabbed Help modal (Getting Started · Use Cases · FAQ · What's New) plus small "?" chips that explain DPI, formats, LUTs, scale bars, and adjustments in plain, methods-aware language — right where you need them.

📄

Lossless PDF & true-DPI export

A new lossless (Flate-compressed) PDF for line art and blots, and both PDF paths now render at the true target DPI instead of screen resolution. Plus auto-arrange for a balanced grid in one click.

↔️

Drag-to-space panels

Hover between two panels, grab the divider, and drag — the gap changes live with a pixel readout. Tap +/− to nudge. Turn on per-gutter spacing to give one row or column its own gap, with one-click reset to uniform.

🅣

Double-click text on a panel

Double-click any panel and type. The label is pinned to that panel — it travels when you reorder — and carries a subtle dark halo so white text stays legible over a bright fluorescence channel. Halos export to SVG too.

🔍

True high-resolution export

PNG, JPEG, and WebP now re-render the whole figure off-screen at the actual target pixel count — so 600 DPI is genuinely 600 DPI, not a 72 DPI image with a relabelled tag. Text and scale bars stay crisp.

↩️

Universal undo & redo

Ctrl+Z now reaches everything — deleting a panel, reordering, a brightness slider, a crop, a layout change, a gutter drag — not just annotations. State is snapshotted while loaded images are held by reference, so undo stays cheap even with large TIFFs open.

🏷️

One-click row & column labels

A single toolbar button drops or restores both row and column headers at once, instead of hunting for two separate checkboxes.

🛡️

Reliability & accessibility hardening

Corrupt files, clipboard, and oversized exports now report errors honestly instead of failing silently. Slow exports show progress; a stale canvas flags itself. Slider dragging stays smooth on large multi-panel figures. Visible focus outlines, labelled buttons, and higher-contrast theme text round it out.

✂️

Batch crop

Draw the crop on the first image to lock its size and aspect ratio; every following image opens with that same box, centered, ready to drag into position. Identical dimensions across every panel — only the position changes.

🖼️

Panel borders with inset

A positive inset floats the border frame inside the image for a clean inner frame; per-panel overrides let individual panels carry their own border width, color, and inset.

✂️

Pre-use crop editor

Every dropped image opens in a crop editor before entering the canvas. Queue multiple files — each gets its own crop step. The cropped version is what gets added; the original stays untouched on disk.

✦

Freeform canvas mode

Switch the layout toggle and place images, shapes, text, and AI icons freely — like Inkscape or PowerPoint. Snap to grid, align edges, distribute evenly, nudge with arrow keys.

🤖

AI scientific diagram generation

25+ scientific subject quick-prompts. BioRender-style cartoon, molecular schematic, medical illustration, and more styles. Gemini API or local Stable Diffusion. Background removal in one click.

📊

ROI quantification + cell counting

Draw a region and measure mean intensity, integrated density, area in px² and µm². Line profile plots for fluorescence. Threshold-based connected-component cell counting. All measurements export as CSV.

⚡

Exposure analysis

Per-panel histogram analysis detects overexposure, pixel saturation, underexposure, and low dynamic range — before you export and before a reviewer notices.

📋

Reproducibility log in every PNG

Every PNG carries tEXt metadata: software, DPI, per-panel LUT/levels/crop settings, and the last 20 log entries. Readable in FIJI, ImageJ, and any EXIF viewer.

🎨

Three UI themes

Dark (high contrast), Lab (warm indigo — easy on the eyes for long sessions), and Light (white background). Toggle in the header. Preference persists across sessions.

🔬

Auto scale bar detection

Scans the bottom quarter of any microscope image for a horizontal bar, asks what physical length it represents, and sets µm/px calibration automatically.

📄

Multi-page PDF export

Set how many rows per page. FigureLab renders each slice independently and assembles a proper multi-page PDF — one Object per page, correct MediaBox per slice. Built for supplementary figure sets.

📎

TIFF & Zeiss LSM metadata

Parses TIFF IFD tags (XResolution, ResolutionUnit) and Zeiss CZ-LSMINFO VoxelSizeX from raw file bytes. Calibrates µm/px without any manual entry. Works with multi-directory TIFFs too.

🔗

Shareable settings links

Encodes layout, style, annotations, and per-panel settings into a URL hash. No server — the link is entirely self-contained. Recipient drops their own images and settings apply automatically.

⧉

Panel comparison + difference overlay

Side-by-side view of any two panels with zoom (1–8×), pixel inspector on hover, per-panel intensity stats, and an amplified pixel-delta difference map with an average divergence score.
